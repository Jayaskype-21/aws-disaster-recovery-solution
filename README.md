# AWS Disaster Recovery Solution

Designed a disaster recovery architecture for Kuvio Innovations & Services using AWS.  
Ensured business continuity and data reliability through automated backups and DNS failover.

## 🧰 AWS Services Used
- Amazon EC2 – Backup instances
- Amazon S3 – Data backup and replication
- AWS Backup – Centralized backup automation
- Amazon Route 53 – DNS failover

## 🧩 Outcome
Achieved high availability and minimal downtime during simulated outages.
